ao aplicativo.

Você será o primeiro administrador da sua companhia. Este cadastro é feito uma vez.

1. Crie seu usuário no Supabase

Abra os usuários do projeto. Escolha Add user → Create new user, informe seu e-mail e crie uma senha exclusiva com pelo menos 12 caracteres. Mantenha Auto Confirm User ativado.

Abrir usuários do Supabase

A senha é digitada somente no Supabase. Use o mesmo e-mail na etapa abaixo.

2. Identifique o administrador

Preencha os dados e copie o código. Eles são usados apenas para gerar o texto nesta página.

Ver o código que será executado

3. Execute no SQL Editor

Abra uma nova consulta, cole com ⌘ + V no Mac e toque em Run. A mensagem Success. No rows returned confirma a execução.

Abrir SQL Editor

4. Entre no aplicativo

Abra o app e use o e-mail e a senha criados na primeira etapa. Como administrador, você poderá cadastrar uma obra e publicar seu primeiro serviço.

Abrir aplicativo
